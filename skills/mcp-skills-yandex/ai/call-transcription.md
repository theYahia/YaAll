# Транскрипция и анализ звонков

## Что делает
Принимает аудиозапись звонка, транскрибирует речь в текст через SaluteSpeech, затем анализирует содержание через YandexGPT: извлекает обещания, определяет тональность, считает quality score менеджера.

## Требуемые серверы
- `npx -y @theyahia/salutespeech-mcp` — распознавание речи (STT), конвертация аудио в текст
- `npx -y @theyahia/yandexgpt-mcp` — LLM-анализ транскрипта (обещания, тональность, оценка)

## Переменные окружения
| Переменная | Сервер | Где получить |
|-----------|--------|-------------|
| SALUTE_AUTH_KEY | salutespeech-mcp | https://developers.sber.ru/portal/products/salutespeech |
| YANDEX_API_KEY | yandexgpt-mcp | https://console.yandex.cloud/folders → API keys |
| YANDEX_FOLDER_ID | yandexgpt-mcp | https://console.yandex.cloud/folders |

## Шаги

1. **Транскрибировать аудио** — вызвать `recognize_speech` из salutespeech-mcp:
   - Передать аудио в Base64 (WAV/OGG/MP3)
   - Получить полный текст разговора с таймкодами

2. **Извлечь обещания и действия** — вызвать `complete` из yandexgpt-mcp:
   - Системный промпт: «Ты — аналитик звонков. Из транскрипта звонка извлеки: 1) Все обещания менеджера клиенту, 2) Все договорённости, 3) Следующие шаги (next actions)»
   - Передать транскрипт как user message

3. **Определить тональность и качество** — вызвать `complete` из yandexgpt-mcp:
   - Системный промпт: «Оцени звонок менеджера по шкале 1-10 по критериям: приветствие, выявление потребности, работа с возражениями, закрытие, вежливость. Определи общую тональность (позитивная/нейтральная/негативная). Дай итоговый quality score.»
   - Передать транскрипт как user message

4. **Сформировать отчёт** — объединить результаты в структурированный отчёт:
   - Транскрипт (полный текст)
   - Обещания и действия
   - Quality score (1-10)
   - Тональность
   - Рекомендации по улучшению

## Пример использования
«Проанализируй запись звонка менеджера Иванова с клиентом, файл call_2026-04-01.wav»

«Транскрибируй звонок и покажи quality score»

## Обработка ошибок
- Если аудио не распознаётся (пустой результат) → попробовать другой формат или проверить качество записи
- Если SALUTE_AUTH_KEY истёк → обновить токен на developers.sber.ru
- Если транскрипт слишком длинный (>30000 символов) → разбить на части и анализировать по частям

## Ожидаемый результат
Пользователь получает полный отчёт по звонку: текст разговора, список обещаний, quality score менеджера (1-10), тональность, и конкретные рекомендации по улучшению навыков продаж.
