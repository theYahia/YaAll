# Голосовой чат-бот

## Что делает
Реализует полный цикл голосового взаимодействия: принимает входящий звонок через Voximplant, распознаёт речь клиента через Yandex SpeechKit, генерирует ответ через YandexGPT, синтезирует речь и воспроизводит клиенту. Работает как автоматический оператор для типовых обращений.

## Требуемые серверы
- `npx -y @theyahia/yandex-speechkit-mcp` — распознавание речи (STT) и синтез речи (TTS)
- `npx -y @theyahia/yandexgpt-mcp` — генерация ответов на запросы клиента
- `npx -y @theyahia/voximplant-mcp` — управление звонками, история, доставка голоса

## Переменные окружения
| Переменная | Сервер | Где получить |

## Шаги

1. **Принять аудио от клиента** — получить входящий аудиопоток:
   - Аудио приходит из Voximplant (запись звонка или реалтайм-чанк)
   - Получить историю текущих звонков через `get_call_history` из voximplant-mcp

2. **Распознать речь** — вызвать `recognize` из yandex-speechkit-mcp:
   - Передать аудио в Base64
   - Язык: ru-RU
   - Получить текст запроса клиента

3. **Сгенерировать ответ** — вызвать `complete` из yandexgpt-mcp:
   - Системный промпт: «Ты — голосовой оператор компании [название]. Отвечай кратко (до 3 предложений), по делу. Если не можешь помочь — предложи переключить на живого оператора. Формат: только текст ответа, без маркдауна.»
   - Модель: yandexgpt-lite (для быстрого ответа, <2 сек)
   - temperature: 0.3 (точные ответы, минимум креатива)
   - maxTokens: 200 (короткие ответы для голоса)
   - Передать контекст диалога (предыдущие реплики)

4. **Синтезировать речь** — вызвать `synthesize` из yandex-speechkit-mcp:
   - Передать текст ответа
   - Голос: alena (женский) или filipp (мужской)
   - Скорость: 1.0
   - Получить аудио в Base64

5. **Отправить ответ клиенту** — доставить аудио через Voximplant:
   - Проиграть синтезированный ответ в текущем звонке
   - Если бот не справляется → вызвать `get_users` из voximplant-mcp для поиска свободного оператора
   - Опционально: отправить SMS с резюме разговора через `send_sms` из voximplant-mcp

## Пример использования
«Настрой голосовой бот для обработки входящих звонков: приветствие, ответы на FAQ, переключение на оператора»

«Обработай запись звонка: распознай что сказал клиент и сгенерируй ответ»

«Создай автоответчик для нерабочего времени с синтезом речи»

## Обработка ошибок
- Если речь не распознана (тишина, шум) → попросить клиента повторить (синтезировать «Извините, не расслышал. Повторите, пожалуйста.»)
- Если YandexGPT отвечает дольше 3 сек → проиграть заглушку «Одну секунду, обрабатываю ваш запрос»
- Если бот не может ответить (3 неудачные попытки) → переключить на живого оператора
- Если Voximplant API недоступен → логировать ошибку, попробовать fallback

## Ожидаемый результат
Рабочий голосовой бот, который принимает звонки, понимает речь клиента, генерирует релевантные ответы и озвучивает их. Обрабатывает типовые обращения (часы работы, статус заказа, FAQ) без участия оператора, экономя до 70% ресурсов call-центра.
