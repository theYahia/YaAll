# Генерация контента на русском

## Что делает
Принимает бриф (тема, формат, тон, аудитория) и генерирует готовый текст на русском языке: описание товара, пост для VK, email-рассылку, статью для блога. Поддерживает подстройку тона (формальный, разговорный, экспертный).

## Требуемые серверы
- `npx -y @theyahia/yandexgpt-mcp` — генерация текста через YandexGPT, подсчёт токенов

## Переменные окружения
| Переменная | Сервер | Где получить |
|-----------|--------|-------------|
| YANDEX_API_KEY | yandexgpt-mcp | https://console.yandex.cloud/folders → API keys |
| YANDEX_FOLDER_ID | yandexgpt-mcp | https://console.yandex.cloud/folders |

## Шаги

1. **Принять бриф** — определить параметры генерации:
   - Формат: product_description | vk_post | email | blog_article | telegram_post
   - Тон: formal | casual | expert | friendly | persuasive
   - Аудитория: B2B | B2C | молодёжь | профессионалы
   - Длина: short (до 500 символов) | medium (500-2000) | long (2000+)

2. **Сгенерировать текст** — вызвать `complete` из yandexgpt-mcp:
   - Системный промпт подбирается по формату:
     - product_description: «Ты — опытный копирайтер e-commerce. Напиши продающее описание товара. Используй конкретные преимущества, не воду. Формат: заголовок + 3-5 абзацев + буллеты с характеристиками.»
     - vk_post: «Ты — SMM-менеджер. Напиши пост для VK. Первое предложение — цепляющий хук. Используй эмодзи уместно. Заверши призывом к действию.»
     - email: «Ты — email-маркетолог. Напиши письмо для рассылки. Тема письма + прехедер + тело + CTA-кнопка. Не спам, а полезный контент.»
     - blog_article: «Ты — контент-маркетолог. Напиши экспертную статью. H2 заголовки, конкретные примеры, выводы.»
   - Модель: yandexgpt (полная) для длинных текстов, yandexgpt-lite для коротких
   - temperature: 0.7 для креативных текстов, 0.3 для описаний товаров

3. **Подсчитать токены** — вызвать `tokenize` из yandexgpt-mcp:
   - Проверить длину результата
   - Если текст слишком длинный — обрезать и добавить финальный абзац

4. **Подстроить тон (при необходимости)** — повторный вызов `complete`:
   - Если пользователь просит «сделай формальнее» или «добавь юмора» — передать оригинальный текст с инструкцией по корректировке

## Пример использования
«Напиши описание товара: беспроводные наушники TWS с ANC, для молодёжи, стиль casual»

«Сгенерируй пост для VK про наш новый курс по Python, целевая аудитория — начинающие разработчики»

«Напиши email-рассылку о летней распродаже, тон — дружелюбный, B2C»

## Обработка ошибок
- Если бриф слишком расплывчатый → запросить уточнение (аудитория, формат, ключевой message)
- Если результат содержит галлюцинации (ложные факты) → предупредить пользователя проверить фактуру
- Если YANDEX_API_KEY не задан → инструкция по получению ключа

## Ожидаемый результат
Пользователь получает готовый текст в нужном формате и тоне, который можно сразу публиковать или отправлять с минимальными правками. Текст адаптирован под русскоязычную аудиторию и специфику платформы.
