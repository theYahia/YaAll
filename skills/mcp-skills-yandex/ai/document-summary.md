# Суммаризация документов

## Что делает
Принимает текст документа (договор, отчёт, протокол совещания, статья) и создаёт краткую выжимку с ключевыми тезисами, цифрами и решениями. Поддерживает разные форматы вывода: буллеты, executive summary, mind map текстом.

## Требуемые серверы
- `npx -y @theyahia/yandexgpt-mcp` — суммаризация и извлечение ключевых точек через YandexGPT

## Переменные окружения
| Переменная | Сервер | Где получить |
|-----------|--------|-------------|
| YANDEX_API_KEY | yandexgpt-mcp | https://console.yandex.cloud/folders → API keys |
| YANDEX_FOLDER_ID | yandexgpt-mcp | https://console.yandex.cloud/folders |

## Шаги

1. **Оценить размер документа** — вызвать `tokenize` из yandexgpt-mcp:
   - Подсчитать количество токенов в документе
   - Если >6000 токенов → использовать yandexgpt-32k или разбить на части
   - Если <6000 токенов → использовать yandexgpt-lite (быстрее и дешевле)

2. **Суммаризировать текст** — вызвать `summarize` из yandexgpt-mcp:
   - Передать текст документа
   - Инструкция зависит от формата вывода:
     - Буллеты: «Выдели 5-10 ключевых тезисов из текста. Каждый тезис — одно предложение. Сохрани все цифры, даты и имена.»
     - Executive summary: «Напиши краткое резюме для руководителя (3-5 абзацев). Начни с главного вывода, затем ключевые детали.»
     - Решения/действия: «Извлеки все решения, договорённости и следующие шаги (action items). Для каждого укажи ответственного (если есть) и срок.»

3. **Извлечь ключевые точки** — вызвать `complete` из yandexgpt-mcp:
   - Системный промпт: «Из документа извлеки: 1) Ключевые цифры и метрики, 2) Упомянутые имена и организации, 3) Даты и дедлайны, 4) Риски и проблемы. Формат: JSON с полями numbers, entities, dates, risks.»
   - Передать оригинальный текст

4. **Сформировать итоговый отчёт** — объединить суммари и ключевые точки:
   - Краткое содержание (суммаризация)
   - Ключевые цифры
   - Упомянутые лица и организации
   - Даты и дедлайны
   - Выявленные риски

## Пример использования
«Суммаризируй этот договор, выдели ключевые условия и сроки»

«Сделай выжимку из протокола совещания, покажи action items»

«Краткое содержание отчёта на 50 страниц — в 10 буллетов»

## Обработка ошибок
- Если документ превышает 32k токенов → разбить на главы/разделы, суммаризировать каждый, затем сделать мета-суммари
- Если текст на иностранном языке → предупредить пользователя, что качество снизится (YandexGPT оптимизирован под русский)
- Если YANDEX_API_KEY не задан → инструкция по получению

## Ожидаемый результат
Пользователь получает структурированную выжимку документа: краткое содержание (5-10 предложений), список ключевых цифр, перечень action items с ответственными, и выделенные риски. Экономит 15-20 минут на каждом документе.
