# Аудит Яндекс.Директ

## Что делает
Проводит комплексный аудит рекламных кампаний в Яндекс.Директ: анализирует структуру кампаний, эффективность ключевых слов, качество объявлений и сопоставляет с данными поведения из Метрики.

## Требуемые серверы
- `npx -y @theyahia/yandex-direct-mcp` — кампании, группы, объявления, ключи, статистика
- `npx -y @theyahia/yandex-metrika-mcp` — поведенческие метрики и конверсии

## Переменные окружения
| Переменная | Сервер | Где получить |
|---|---|---|
| `YANDEX_DIRECT_TOKEN` | yandex-direct-mcp | oauth.yandex.ru → Яндекс.Директ |
| `YANDEX_METRIKA_TOKEN` | yandex-metrika-mcp | oauth.yandex.ru → Яндекс.Метрика |

## Шаги
1. Вызвать `list_campaigns` — получить все кампании, отфильтровать активные
2. Вызвать `get_statistics` за последние 30 дней — расходы, клики, показы, CTR, CPC по кампаниям
3. Вызвать `list_ad_groups` для топ-кампаний — проверить структуру групп
4. Вызвать `list_keywords` — выявить слова с высоким расходом и низким CTR
5. Вызвать `list_ads` — проверить качество текстов объявлений
6. Вызвать `get_report` (yandex-metrika) по UTM-меткам — отказы и конверсии с рекламного трафика
7. Сформировать аудит: проблемные кампании, дорогие ключи без конверсий, рекомендации

## Пример использования
«Сделай аудит моего Яндекс.Директ за последний месяц»

## Обработка ошибок
- Если нет активных кампаний → сообщить, предложить проверить архивные
- Если Метрика недоступна → аудит только по данным Директ, предупредить об отсутствии поведенческих метрик
- Если слишком много кампаний (>50) → анализировать топ-20 по расходу

## Ожидаемый результат
Аудит-отчёт: общая эффективность аккаунта, список проблемных кампаний с причинами, ключевые слова на отключение, рекомендации по текстам объявлений, потенциальная экономия бюджета.
