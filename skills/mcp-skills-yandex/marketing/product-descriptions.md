# Генерация описаний товаров

## Что делает
Выгружает товары из МоегоСклада (название, артикул, характеристики), генерирует через YandexGPT продающие описания для сайта или маркетплейса.

## Требуемые серверы
- `npx -y @theyahia/yandexgpt-mcp` — генерация текста
- `npx -y @theyahia/moysklad-mcp` — каталог товаров и характеристики

## Переменные окружения
| Переменная | Сервер | Где получить |
|---|---|---|
| `YANDEX_API_KEY` | yandexgpt-mcp | console.cloud.yandex.ru → API-ключ |
| `YANDEX_FOLDER_ID` | yandexgpt-mcp | console.cloud.yandex.ru → ID каталога |
| `MOYSKLAD_TOKEN` | moysklad-mcp | МойСклад → Настройки → Доступ к API |

## Шаги
1. Вызвать `search_products` (moysklad) — найти товары по названию, категории или артикулу
2. Вызвать `get_product` (moysklad) для каждого товара — получить полные характеристики
3. Для каждого товара вызвать `complete` (yandexgpt) — сгенерировать продающее описание на основе характеристик
4. При необходимости вызвать `summarize` (yandexgpt) — создать короткую версию для карточки
5. Вывести результат: полное описание + короткое описание для каждого товара

## Пример использования
«Сгенерируй описания для всех товаров из категории "Электроника" в МоемСкладе»

## Обработка ошибок
- Если товары не найдены → уточнить критерии поиска, показать доступные категории
- Если у товара нет характеристик → сгенерировать базовое описание по названию, предупредить о низком качестве
- Если YandexGPT вернул ошибку лимита → обработать batch-ами с паузами

## Ожидаемый результат
Для каждого товара: полное продающее описание (150-300 слов) и короткое описание (50-80 слов) с ключевыми преимуществами и характеристиками.
