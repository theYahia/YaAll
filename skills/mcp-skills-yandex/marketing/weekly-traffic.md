# Еженедельный отчёт по трафику

## Что делает
Формирует еженедельный отчёт по трафику сайта из Яндекс.Метрики: визиты, пользователи, отказы, источники, топ страниц, сравнение с предыдущей неделей.

## Требуемые серверы
- `npx -y @theyahia/yandex-metrika-mcp` — счётчики, отчёты, трафик, источники

## Переменные окружения
| Переменная | Сервер | Где получить |
|---|---|---|
| `YANDEX_METRIKA_TOKEN` | yandex-metrika-mcp | oauth.yandex.ru → Яндекс.Метрика (права: чтение статистики) |

## Шаги
1. Вызвать `list_counters` — определить счётчик сайта (или использовать указанный ID)
2. Вызвать `get_traffic_summary` за текущую неделю (пн-вс) — визиты, просмотры, пользователи, отказы, средняя длительность
3. Вызвать `get_report_comparison` — сравнить текущую неделю с предыдущей
4. Вызвать `get_traffic_sources` — разбивка по каналам (поиск, прямые, рефералы, соцсети, реклама)
5. Вызвать `get_top_pages` — топ-10 страниц по просмотрам
6. Сформировать отчёт с динамикой (рост/падение в %) и выводами

## Пример использования
«Еженедельный отчёт по трафику для счётчика 12345678»

## Обработка ошибок
- Если счётчик не найден → вывести список доступных счётчиков через `list_counters`
- Если данные за неделю неполные (текущая неделя) → взять доступные дни и предупредить

## Ожидаемый результат
Структурированный отчёт: общий трафик (визиты, пользователи, отказы), сравнение с прошлой неделей (% роста), топ-5 источников, топ-10 страниц, краткие выводы и рекомендации.
