# SEO-аудит

## Что делает
Проводит SEO-аудит сайта: проверяет индексацию в Яндексе, анализирует поисковые запросы (позиции, CTR, клики), сопоставляет с данными трафика из Метрики и выдаёт рекомендации по оптимизации.

## Требуемые серверы
- `npx -y @theyahia/yandex-webmaster-mcp` — сайты, поисковые запросы, индексация
- `npx -y @theyahia/yandex-metrika-mcp` — трафик, источники, топ страниц

## Переменные окружения
| Переменная | Сервер | Где получить |
|---|---|---|
| `YANDEX_WEBMASTER_TOKEN` | yandex-webmaster-mcp | oauth.yandex.ru → Яндекс.Вебмастер |
| `YANDEX_METRIKA_TOKEN` | yandex-metrika-mcp | oauth.yandex.ru → Яндекс.Метрика |

## Шаги
1. Вызвать `get_hosts` (yandex-webmaster) — получить список сайтов, выбрать нужный
2. Вызвать `get_indexing` — проверить статус индексации (проиндексировано / исключено / ошибки)
3. Вызвать `get_search_queries` — топ поисковых запросов с кликами, показами, CTR, средней позицией
4. Вызвать `get_traffic_sources` (yandex-metrika) — доля органического трафика
5. Вызвать `get_top_pages` (yandex-metrika) — топ страниц по трафику из поиска
6. Сопоставить: страницы с высокими показами, но низким CTR (проблемы с title/description)
7. Сформировать аудит с приоритизированными рекомендациями

## Пример использования
«Проведи SEO-аудит сайта example.ru»

## Обработка ошибок
- Если сайт не добавлен в Вебмастер → предложить добавить, показать доступные сайты
- Если нет данных по запросам (новый сайт) → сообщить, дать рекомендации по начальной оптимизации
- Если Метрика недоступна → аудит только по Вебмастеру

## Ожидаемый результат
SEO-отчёт: статус индексации, топ-20 запросов с позициями, страницы с потенциалом роста (высокие показы, низкий CTR), доля органики в общем трафике, приоритизированные рекомендации по оптимизации.
