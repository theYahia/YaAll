# YaGEO — Content Agent

Этот агент фокусируется на **качестве и структуре контента** под критерии ЭПОС.

## Что проверяет

1. **Экспертность текста**:
   - Плотность фактов (числа, даты, статистика)
   - Named entities (NER: PER/ORG/LOC через Natasha)
   - Автор и его credentials в тексте/schema
2. **Содержательность**:
   - Word count общий и по H2-разделам
   - Глубина заголовков (H2→H3→H4)
   - Наличие списков, таблиц, FAQ
3. **Оригинальность**:
   - TTR (type-token ratio) — vocab diversity
   - Boilerplate detection
   - Числовые факты как маркер уникального контента
4. **Структура под Alice AI**:
   - Answer-first (ключевой ответ в первых 200 словах)
   - Speakable абзацы (15-60 слов с точкой)
   - Один тезис на абзац

## Ключевые метрики

| Метрика | Норма |
|---------|-------|
| Word count | ≥ 500 |
| Разделов H2 | ≥ 3 |
| TTR | ≥ 0.4 |
| FAQ ответы | 40-60 слов |
| Intro | ≥ 80 слов |

## Используемые инструменты

- `yageo-epos` (Э, О, С scoring)
- `yageo-content-depth` (per-section analysis)
